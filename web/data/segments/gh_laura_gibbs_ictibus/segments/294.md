Rūpe ēditissimā in Agnī tergum dēvolat Aquila. Vidēns id Corvus imitārī, velut Sīmia, gestit Aquilam. In Ariētis vellus sē dimittit, dīmissus impedītur, impedītus comprehenditur, comprehēnsus proiicitur puerīs. Nōn aliōrum, sed suā sē quisque virtūte aestimet. Tuō tē pede mētīre, inquit Horātius. Id velīs, id tentēs quod possīs.
