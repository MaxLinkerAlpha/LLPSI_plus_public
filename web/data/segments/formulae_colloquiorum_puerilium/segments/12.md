-- Naevius --
Quō tū nunc abīs?

-- Osvaldus --
Domum mē cōnferō.

-- Naevius --
Quid domī agēs?

-- Osvaldus --
Sūmam ientāculum.

-- Naevius --
Quānam itūrus es?

-- Osvaldus --
Hāc per forum.

-- Naevius --
Comitābor tē.

-- Osvaldus --
Nihil opus est.

-- Naevius --
Āversāris mē?

-- Osvaldus --
Nōn, sed parcō.

-- Naevius --
Nihil est quod agam.

-- Osvaldus --
Lubēns tē accipiō.
