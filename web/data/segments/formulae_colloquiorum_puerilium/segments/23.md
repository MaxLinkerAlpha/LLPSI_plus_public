-- Benedictus --
Ubi herī fuerās?

-- Chrīstophorus --
Quōnam tempore?

-- Benedictus --
Statim ā prandiō.

-- Chrīstophorus --
Domī meae lāvī.

-- Benedictus --
Quam diū lāvistī?

-- Chrīstophorus --
Tōtam fermē hōram.

-- Benedictus --
Quis tēcum lāvit?

-- Chrīstophorus --
Parentēs meī.

-- Benedictus --
Lōtus quid fēcerās?

-- Chrīstophorus --
Siccābam capillōs.

-- Benedictus --
Cūr nōn ībās in scholam?

-- Chrīstophorus --
Pater prohibēbat.

-- Benedictus --
Cūr prohibēbat?

-- Chrīstophorus --
Nam caput madēbat.

-- Benedictus --
Dēlicātus puer es!
