-- Kiliānus --
Heus tū, hūc sēde!

-- Lamperdus --
Quid istīc facerem?

-- Kiliānus --
Discāmus simul.

-- Lamperdus --
Rem grātam offers.

-- Kiliānus --
Alter alterum doceat.

-- Lamperdus --
Perlubēns pāreō.

-- Kiliānus --
Quidnam tū discis?

-- Lamperdus --
Discō legere.

-- Kiliānus --
Ubi nunc legis?

-- Lamperdus --
In hōc foliō.

-- Kiliānus --
Scīs lēctiōnem?

-- Lamperdus --
Nōn admodum prōmptē.

-- Kiliānus --
Quotiēs recitāstī?

-- Lamperdus --
Recitāvi semel, bis, ter, quater.

-- Kiliānus --
Cuinam recitāstī?

-- Lamperdus --
Rēctōrī scholae.

-- Kiliānus --
Sī quid nescīs, rogā.

-- Lamperdus --
Quī hoc legam?

-- Kiliānus --
Collige litterās.

-- Lamperdus --
Tū mē observā.

-- Kiliānus --
Ut haesitās linguā?

-- Lamperdus --
Sīc assuētus sum.

-- Kiliānus --
Dēsuēsce rūrsus.

-- Lamperdus --
Pergam legere.

-- Kiliānus --
Iam verba praecipitās.

-- Lamperdus --
Tū melius docē.

-- Kiliānus --
Sīc distīnctē legās.

-- Lamperdus --
Tam clārē haud queō.

-- Kiliānus --
Ūsū addisce.

-- Lamperdus --
Tentābō quid possim.
