-- Iōdōcus --
Heus, heus, manē!

-- Kiliānus --
Quid vīs? Cūr maneam?

-- Iōdōcus --
Est quod tēcum loquar.

-- Kiliānus --
Modo nōn vacat.

-- Iōdōcus --
Tantillum pernegēs?

-- Kiliānus --
Mitte mē modo.

-- Iōdōcus --
Nōn tē dīmittam.

-- Kiliānus --
Ēnecās mē, furcifer!

-- Iōdōcus --
Tantum verbum audī.

-- Kiliānus --
Ecquid meā refert?

-- Iōdōcus --
Permultum scīlicet.

-- Kiliānus --
Quid negōtiī est? Dīc.

-- Iōdōcus --
Dīcam, modo dēs fidem.

-- Kiliānus --
Quam fidem darem?

-- Iōdōcus --
Tē nōn fore invidum.

-- Kiliānus --
Dō fidem, fīdus erō.

-- Iōdōcus --
Adhibē hūc aurem.

-- Kiliānus --
Quid aurem? Clārē dīc.

-- Iōdōcus --
Arcāna rēs est.

-- Kiliānus --
Tamen sōlī sumus.

-- Iōdōcus --
Clārē nōn dīcam.

-- Kiliānus --
Lūdificāris nunc mē!

-- Iōdōcus --
Id est quod voluī.

-- Kiliānus --
Haud impūne hoc ferēs.
