-- Iācōbus --
Apage tē hinc.

-- Chrīstophorus --
Satis imperiōsē.

-- Iācōbus --
Hīc mihi locus est.

-- Chrīstophorus --
Atquī ego negō.

-- Iācōbus --
Prior hīc sēdī.

-- Chrīstophorus --
Cūr autem surrēxistī?

-- Iācōbus --
Negōtium mihi fuit.

-- Chrīstophorus --
Quid signī posuistī?

-- Iācōbus --
Nōn vidēs librum?

-- Chrīstophorus --
Liber istīc iacet.

-- Iācōbus --
At tū sēmōvistī.

-- Chrīstophorus --
Id factum pernegō.

-- Iācōbus --
Quīn tandem cēdēs?

-- Chrīstophorus --
Tū mē vī extrūdēs?

-- Iācōbus --
Nisi volēns cesseris.

-- Chrīstophorus --
Hoc dīcam magistrō.

-- Iācōbus --
Sūsque dēque ferō.
