-- Tīmotheus --
Vae nōbīs, Vite!

-- Vitus --
Quid est? Quid tremis?

-- Tīmotheus --
Ego et tū perīmus.

-- Vitus --
Quid ita? Quā dē causā?

-- Tīmotheus --
Praeceptor venit.

-- Vitus --
Quid ex tē audiō?

-- Tīmotheus --
Vae nostrīs nātibus!

-- Vitus --
Ubi is est, obsecrō?

-- Tīmotheus --
Per gradūs ascendit.

-- Vitus --
Quis id ait? Quis vīdit?

-- Tīmotheus --
Egomet inquam vīdī!

-- Vitus --
Vīditne nōs lūdere?

-- Tīmotheus --
Id est quod timeō.

-- Vitus --
Quid ergō agēmus?

-- Tīmotheus --
Āmovē orbiculōs.

-- Vitus --
Rēctē admonēs.

-- Tīmotheus --
Explicēmus librōs.

-- Vitus --
Certē astūtus es.

-- Tīmotheus --
Sīc rēbit nōs discere.
